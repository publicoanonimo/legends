# Legends

Esqueleto de aplicación web con React y Vite.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo

```bash
npm install
npm run dev
```

Abre en el navegador la dirección que indique Vite (normalmente `http://localhost:5173`).

## Producción

```bash
npm run build
npm run preview
```

El código de la aplicación está en `src/`. La carpeta `dist/` se genera al compilar.
